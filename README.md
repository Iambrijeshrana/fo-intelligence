# F&O Intelligence

AI-powered F&O analysis for Indian markets — Nifty, BankNifty, Sensex, Crude Oil, Gold, Natural Gas.

## Features
- Live news + global cues
- Technical analysis (trend, support/resistance, RSI, MACD)
- OI data (PCR, max pain, call/put buildup)
- Trade suggestions (strike, entry, target, stop loss)
- Deep analysis (Greeks, geopolitical, FII/DII)

## Deploy to GitHub Pages (5 mins)

1. Create new repository on GitHub named `fo-intelligence`
2. Upload `index.html` to the repository
3. Go to **Settings → Pages → Source → main branch → Save**
4. Your URL will be: `https://yourusername.github.io/fo-intelligence`

## Setup
1. Get free API key from [openrouter.ai/keys](https://openrouter.ai/keys)
2. Open the app URL → enter API key once → done
